# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 温度折算与稳定性复核

- **折算规则** `src/temperature/conversion.ts`：每个场馆保存基准温度与簧片/唇管敏感系数（音分/℃），录入时按 `折算偏差 = 实测偏差 − k × (现场温度 − 基准温度)` 折回基准温度；同一音管相邻两次读数温升/温降超过阈值即列入待复检。
- **本地存档** `src/storage/localStore.ts`：读数、场馆参数、已签发报告全部存入 localStorage；折算结果随读数固化，修改场馆参数不追溯历史读数，已复核读数保留不改。
- **复核页面** `src/pages/ReviewPage.tsx`：待复检列表与已复核历史分开展示；复核只追加结论。对应场馆存在待复检读数时，维护报告（`src/pages/ReportPage.tsx`）不能签发。
