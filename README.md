# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

给管风琴维护人员使用的音管调音记录前端：记录教堂/音乐厅、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注，并内置温度折算与稳定性复核流程。

## 温度折算与复核流程

- **折算规则**：每个场馆保存基准温度（℃）与簧片、唇管两条敏感系数（音分/℃）。录入时按
  `折算后偏差 = 实测偏差 − 系数 × (现场温度 − 基准温度)` 折回基准温度，录入前可实时预览。
- **待复检**：现场温度相对基准温度升/降超过该场馆阈值（℃）的读数自动列入待复检队列。
- **签发闸门**：报告期（上次签发至今）内仍有待复检读数的场馆，维护报告不能签发；全部复核通过后放行。
- **历史保留**：读数落库时快照当时的基准温度与系数，已复核的历史读数继续保留，不随后续规则调整而改变。

## 模块划分（分开维护）

| 模块 | 职责 |
| --- | --- |
| `src/domain/temperature.ts` | 折算规则：系数选取、温度折算、阈值判定（纯函数） |
| `src/data/store.ts` | 本地存档：localStorage 读写、读数组装、报告周期计算 |
| `src/components/RecheckPage.tsx` | 复核页面：待复检队列 + 已复核历史 |
| `src/components/EntryForm.tsx` | 录入页：实测录入 + 实时折算预览 |
| `src/components/ReportPage.tsx` | 维护报告页：按场馆汇总与签发 |
| `src/components/VenueSettings.tsx` | 场馆页：基准温度 / 系数 / 阈值维护 |
